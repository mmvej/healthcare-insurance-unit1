What each variable means

A variable is a field recorded for each row. The original dataset contains seven variables; age band is an extra field created for this analysis. Each row is a source record, not a verified unique person.

Dataset variables and the age-band filter
VariableType / valuesPlain-language definition
Age
age		Whole number
18–64 in this file		The insured person's recorded age, interpreted as years. The file does not provide a date of birth or the date when age was recorded.
Sex
sex		Category
female or male		The sex label supplied in the file. The publisher describes it as “gender”, but does not explain how it was collected. These two labels do not represent every possible sex or gender identity.
Body mass index
bmi		Decimal number
15.96–53.13 in this file		BMI is a measure based on weight relative to height. It is calculated as weight in kilograms divided by height in metres squared (kg/m²). BMI alone is not a diagnosis or a direct measurement of body fat.
Covered dependants
children		Whole-number count
0–5 in this file		The number of dependants covered, according to the publisher. Although the column is named “children”, the source description calls them dependants. It is not a confirmed count of everyone in the household or a person's total number of children.
Smoking status
smoker		Category
yes or no		Whether the record is classified as a smoker by the source. The file does not explain when status was recorded, smoking frequency, or how former smokers were classified.
Region
region		Category
northeast, northwest, southeast or southwest		The geographic area-of-coverage category supplied for the record. The retrieved source does not confirm the country, exact boundaries or a precise location. These labels are used for group comparisons.
Recorded charges
charges		Amount in USD
$1,121.87–$63,770.43 in this file		The medical insurance costs incurred for the insured person, as described by the publisher. The dashboard expresses these amounts in USD. The time period and whether the amount was billed or actually paid are not specified. These amounts are not assumed to be insurance premiums, which are the regular payments made to maintain cover. For example, a value of 16,884.92 is displayed as $16,884.92 in recorded charges.
Age band
age_band		Derived ordered category
18–29, 30–44, 45–59 or 60–64		A reporting group created from age for the dashboard filter. The endpoints are included: for example, 18–29 covers ages 18 through 29, and age 30 enters 30–44. These are analysis groups, not clinical categories. The final band is narrower because this sample ends at 64.

Records (n)
The number of rows in the selected group. Matching rows are retained because there is no ID proving that they describe the same person.

Mean
The sum of the selected charge amounts divided by the number of records. Large values can pull the mean upwards.

Median
The middle charge after sorting the values. With an even number of records, it is the average of the two middle values.

Standard deviation (SD)
A measure of how spread out the charges are around the mean, in the same charge units. The table uses sample SD; it is undefined for a single record.

Quartiles and IQR
The first and third quartiles mark the 25th and 75th percentiles. Their difference, the interquartile range (IQR), describes the spread of the middle half of the values.

Association
A pattern in how variables vary together. A difference between groups does not, by itself, prove that one variable caused the difference in charges.

Definitions follow the dataset publisher's description and the inspected CSV. Ranges describe the full downloaded file, not the current filter selection.

Source, limitations and project files

This is a secondary, public teaching dataset: Healthcare Insurance by willian oliveira, version 1, downloaded 27 October 2026. The metadata lists CC0. The original file has seven fields and no missing values. One repeated row is retained because there is no person identifier to prove an error.

The source does not confirm its observation dates, sampling frame or exact geographic boundaries. There are no diagnoses, treatments or enrolment periods. Observed differences are associations. They cannot establish causes, future expenses or appropriate prices or eligibility decisions for individuals.
